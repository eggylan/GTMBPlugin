# GTMBPlugin 帮助文档

本目录收录 GTMBPlugin 各功能的使用说明。部分功能提供图形界面：在聊天框输入 `/openui <界面名>` 即可打开，按提示操作。

## 界面功能

| 界面名 | 文档 | 说明 |
| --- | --- | --- |
| `/openui enchant` | [自定义附魔](EnchantUI.md) | 自定义附魔 UI 的操作指南 |
| `/openui nbteditor` | [NBT 编辑器](NBTEditor.md) | 查看并修改手持物品的 NBT 数据 |
| `/openui cmdbatch` | [指令批处理](CmdBatch.md) | 一次性批量执行大量指令 |
| `/openui changetips` | — | 修改物品注释 |
| `/openui structureimport` | — | 从本地导入自定义结构（仅限PC端） |
